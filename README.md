# Pharmaceutical Sales Time Series Analysis

Time-series exploratory analysis and trend visualization of pharmaceutical drug categories (such as `M01AB` and `M01AE`) using Python, Pandas, and Matplotlib.

## Tech Stack
- **Python**
- **Pandas** (data loading, date parsing, sorting, time-series manipulation)
- **Matplotlib** (trend visualizations)
- **Google Colab**

## Notebook
- `Sales_Time_Series_Analysis.ipynb`: Contains dataset inspection (`salesdaily.csv`) and daily sales trend plots for drug categories.
